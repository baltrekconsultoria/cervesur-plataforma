# Guía de QA manual · UX-07E.C (visor optimizado, indicadores, enlaces, publicación corporativa)

Para el operador, en **Brave (Windows)**, después de actualizar el 8093 (`INSTALACION-PILOTO-ADMIN-8093.md` §9). Ningún caso es **PASS** sin que una persona lo vea; anote resultado, fecha, hora y captura **sin** contraseñas ni enlaces visibles. Los casos A1–A10 de `GUIA-QA-ADMIN-A1-A10.md` siguen vigentes; esta guía añade lo nuevo.

Acceso por túnel: `ssh -N -L 18094:127.0.0.1:8093 usr_cervesur@192.168.200.12` → `https://localhost:18094` (con el certificado de la instancia ya confiado). Para ver el visor hace falta que el operador autorice al menos un informe aprobado: `usuarios.sh informes --agregar <id>` (`MATRIZ-AUTORIZACION-ENLACES.md`).

| ID | Prueba | Pasos | Resultado esperado | Evidencia | PASS / FAIL |
|---|---|---|---|---|---|
| **C1** | Detalle sin filas de etiquetas | `/admin/reportes` → abrir un informe. | Arriba solo el título, las migas, **un** botón «Otros informes (N)» y «← Volver a Reportes»; **ninguna** fila de enlaces/etiquetas «Más informes de…». | Captura | PASS: solo el botón. FAIL: aparecen decenas de etiquetas |
| **C2** | Ventana «Otros informes» | Pulsar el botón. | Ventana con buscador (con el foco), lista desplazable **agrupada por empresa**, nombre completo y código de cada informe, y la marca **«Sin enlace autorizado»** en los no autorizados. El informe abierto no figura. | Captura | PASS si coincide |
| **C3** | Búsqueda y navegación | Escribir parte de un nombre y de un código; elegir un informe. | La lista se reduce («N de M informes»); «Ningún informe coincide…» si no hay; al elegir, abre ese informe y la ventana se cierra. | Capturas | PASS si filtra y navega |
| **C4** | Cierre y teclado | Con la ventana abierta: Escape (con texto en el buscador, el primer Escape lo borra y el segundo cierra), botón «Cerrar», clic fuera de la ventana; Tab repetido. | Cierra de las tres formas; el foco vuelve al botón «Otros informes»; Tab no sale de la ventana. | Nota | PASS si las tres cierran y el foco vuelve |
| **C5** | Área del visor | Abrir un informe **autorizado**. | El informe de Power BI ocupa la mayor parte de la pantalla (casi toda la altura y todo el ancho disponible) sin barra de desplazamiento horizontal. Probar ventana ancha, tablet (820 px) y móvil (360 px; `F12` → modo dispositivo). | 3 capturas | PASS si el visor domina y no hay scroll horizontal |
| **C6** | Informe no autorizado | Abrir uno marcado «Sin enlace autorizado» (o pegar su dirección). | Mensaje «Este informe todavía no está autorizado para mostrarse en el piloto administrativo» (Error 403), sin visor ni enlace; el botón vuelve al listado de Reportes. | Captura | PASS: 403 neutral. FAIL: se muestra el informe |
| **C7** | Títulos largos | Revisar tarjetas, detalle, migas y ventana con nombres largos (p. ej. `DASHBOARD_PRESUPUESTAL_CERVESUR_031`). | Ningún texto se sale de su caja ni invade a otro; sin desplazamiento horizontal. | Capturas | PASS si todo cabe |
| **C8** | Filtros conservados | En `/admin/reportes` aplicar búsqueda/estado, abrir un informe y volver. | Los filtros siguen aplicados (el botón dice «filtros conservados»). | Captura | PASS si se conservan |
| **C9** | Indicadores del panel | `/admin`: comparar las cuatro tarjetas con consultas de solo lectura del administrador de MySQL (`DIAGNOSTICO-INDICADORES-ADMIN.md` §3.5). La leyenda dice «datos reales… (solo lectura)». | Las cifras coinciden; ya no dice «sintéticos». | Cifras anotadas | PASS si coinciden |
| **C10** | Autorización de enlaces (operador) | `usuarios.sh informes --agregar <id>` (frase `AUTORIZO-INFORMES`), recargar el listado; luego `--quitar <id>`; revisar `autorizaciones-informes.log`. | El informe pasa a abrir y deja de abrir; el listado cambia la marca; la bitácora registra fecha, quién, acción e ids (sin enlaces). El 8092 no cambia (`usuarios.sh informes --listar` allí). | Salida | PASS si todo coincide |
| **C11** | Trabajadores sin regresión | Entrar al 8092 con una cuenta de trabajador de prueba. | «Mis informes», «Mis empresas» y el visor igual que antes; el botón «Otros informes» solo lista informes de **sus** empresas. | Captura | PASS si no hay cambios inesperados |
| **C12** | Publicación corporativa (solo cuando se apruebe e instale) | Desde un equipo corporativo, sin importar certificados: `https://informes.<zona>`. | Candado sin advertencias; login de administrador; HSTS (no aplica por el túnel); `https://localhost:18094` sigue funcionando. | Capturas | PASS si no hay advertencias |

Si algo falla: anote el caso y detenga las pruebas; para volver atrás, `scripts/actualizar.sh --revertir <respaldo>` (y `corporativo.sh revertir` para la publicación). Esta guía no autoriza escrituras productivas, nuevos enlaces sin aprobación del responsable de los datos ni la apertura general.
