# Documentación del frontend

Informes y guías generados durante el desarrollo (UX-05 a UX-06B.0), en orden cronológico. **Nota**: se redactaron cuando el frontend
vivía en una carpeta local llamada `Frontend-Dev`; las menciones a `Frontend-Dev`, `UX-Prototipo` o `Revision-Codigo` son históricas.
Hoy el código está en `frontend/` y el backend en `backend/` del mismo repositorio. Las capturas incluidas (`capturas/`) son una selección
sintética (usuarios ficticios, dominio `example.invalid`).
